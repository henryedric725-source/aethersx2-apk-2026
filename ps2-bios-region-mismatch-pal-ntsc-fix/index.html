PS2 BIOS Region Mismatch

PAL vs NTSC BIOS timing and pitch fixes.

On this page

  1. FAQ

PAL titles on USA BIOS often run ~17–20% fast with higher audio pitch. Import PAL BIOS or use USA dumps for NTSC libraries — see which BIOS to use.

FAQ

What is ps2 ntsc bios?

NTSC-U firmware such as SCPH-70012; PAL games may run fast until you import PAL BIOS.
