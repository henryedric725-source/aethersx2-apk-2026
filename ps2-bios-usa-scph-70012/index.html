PS2 BIOS USA (SCPH-70012)

NTSC-U firmware for North American PS2 games on AetherSX2 and PCSX2.

On this page

  1. FAQ

Ps2 bios usa, ps2 american bios, and bios ps2 usa refer to NTSC-U firmware. Default model: SCPH-70012 (also search scph 70012 bin).

SCPH-70012 vs SCPH-39001

Older USA consoles may dump as scph 39001 bin or bios scph 39001. Either works when region matches; see SCPH numbers explained.

SHA-256 (SCPH-70012): c7628a01da23d7d38851aec8403e535581d0f2a781fee5b86b1c648b13a9970d

FAQ

What is the ps2 bios usa file name?

Common dumps are named SCPH-70012.bin or SCPH-39001.bin depending on the console you dumped.

Is ps2 bios download usa the same as NTSC?

Yes — USA firmware is NTSC-U (~60 Hz). See region mismatch guide if PAL games run fast.
